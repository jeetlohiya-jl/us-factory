Factory Print isn't installed

"Print on D50" sends labels to the Factory Print app on this tablet, which prints them on the MakeID D50.

  1. Get factory-print.apk from your admin (GitHub → Actions → "Build Factory Print APK" → Artifacts).
  2. Open it on this tablet and allow installing from that app when Android asks, then Install.
  3. Go back and tap Print on D50 again.
